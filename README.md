# 👟 Shoe App – React Native E-commerce Application

**Shoe App** is a React Native mobile app that replicates core features of popular e-commerce platforms like Daraz, Alibaba, and Amazon. It dynamically fetches product data from an external API and enables users to browse, view product details, and manage their shopping cart — all on the client side.

## 🧰 Tech Stack

- **React Native** – Cross-platform mobile app framework  
- **State Management** – [Zustand](https://github.com/pmndrs/zustand) for lightweight and efficient global state  
- **Styling** – Tailwind CSS via [tailwind-react-native-classnames](https://github.com/jaredh159/tailwind-react-native-classnames)  
- **Data Source** – External API (no backend/server in this project)

## 🎯 Purpose

Built purely with React Native, this project demonstrates how to create a dynamic, responsive e-commerce app frontend using state management and remote data fetching, without requiring a custom backend.

## ✨ Features

- 📋 List products with key info (name, price, image) fetched from API  
- 🔍 Detailed product view on item selection  
- 🛒 Add/remove products in a local cart stored in app state  
- 🛍️ Cart screen showing selected items and total price  
- 🏃‍♂️ Smooth navigation between screens

## 🧩 Why Zustand?

- Minimal setup and boilerplate-free compared to Redux  
- Fast and performant state updates  
- Simple API tailored for React and React Native apps  
- Ideal for managing app-wide state like cart contents in this project
